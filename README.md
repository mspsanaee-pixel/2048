# بازی ۲۰۴۸ (2048)

یک بازی کامل و دقیق ۲۰۴۸ در **یک فایل HTML مستقل** (`index.html`) — بدون هیچ وابستگی به سرور یا کتابخانه. کافیست فایل را در مرورگر باز کنی.

## اجرا

```bash
# روش ۱: باز کردن مستقیم فایل در مرورگر
# index.html را با مرورگر باز کن

# روش ۲: با سرور محلی (پیشنهادی برای پیش‌نمایش)
python3 -m http.server 8000
# سپس: http://localhost:8000
```

## امکانات

- **منطق کامل بازی:** حرکت و ترکیب کاشی‌ها، تولید تصادفی کاشی ۲/۴ (۹۰٪/۱۰٪)، تشخیص برد (۲۰۴۸) و باخت
- **انیمیشن‌های روان:** سر خوردن کاشی‌ها، ظاهر شدن نرم، پاپ شدن هنگام ترکیب و لرزش صفحه در حرکت نامعتبر
- **کنترل‌های متنوع:** کلیدهای جهت‌دار و WASD، کشیدن انگشت/ماوس (سوایپ)، دکمه‌های جهت‌دار روی صفحه
- **واگرد (Undo)** با کلید Z و دکمه اختصاصی — تا ۱۰۰ حرکت قابل بازگشت
- **راهنما (Hint)** با کلید H — بهترین حرکت ممکن را پیشنهاد می‌دهد
- **ذخیره خودکار:** امتیاز، بهترین رکورد و وضعیت بازی در localStorage ذخیره می‌شود
- **افکت‌های صوتی** با WebAudio (بدون فایل خارجی) — قابل قطع و وصل
- **تم روشن/تیره** با ذخیره انتخاب کاربر
- **کنفتی و پیام تبریک** هنگام رسیدن به ۲۰۴۸، با امکان ادامه بازی
- **طراحی واکنش‌گرا و راست‌چین (RTL)** با فونت وزیرمتن، سازگار با موبایل و دسکتاپ
